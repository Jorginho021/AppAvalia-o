# AppAvalia-o



Clone de Interface - Amazon Music UI
Este projeto consiste na recriação da interface de usuário (UI) do aplicativo Amazon Music para a plataforma Android, desenvolvida no Android Studio utilizando XML para o layout e Java para a interatividade básica.   
JPG

🎧 Aplicativo de Referência
Aplicativo: Amazon Music   
JPG

Plataforma: Android   
JPG

Modo: Tema Escuro (Dark Mode)

🛠️ O que foi desenvolvido
Barra Superior de Navegação:

Logotipo "Amazon Music".   
JPG

Abas de navegação (INÍCIO, PODCASTS).   
JPG

Campo de busca para pesquisas rápidas.   
JPG

Seções Principais:

Principais Artistas: Lista com rolagem horizontal contendo fotos circulares dos artistas (ShapeableImageView).   
JPG

Playlists dos Lançamentos: Cards de playlists organizados na horizontal com capas coloridas, títulos e subtítulos.   
JPG

As Músicas Mais Populares: Lista vertical de faixas com capas coloridas, nome da música e nome do artista.   
JPG

Player de Áudio Inferior (Interativo):

Barra fixa no rodapé que é ativada ao clicar em qualquer música.   
PNG


Exibe o nome da faixa e o artista em reprodução.   
PNG


Botões funcionais de controle de mídia: Voltar (⏮), Play/Pausa (▶/⏸) e Avançar (⏭).   
PNG


Ícones ilustrativos de atalhos secundários (volume, repetição, ordem aleatória).   
PNG
